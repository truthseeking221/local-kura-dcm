# Spacing

The spacing scale is **4-pixel-based** (with one half-step at `--space-0-5`). Tokens map to pixel values that don't shift with density — density controls layout heights (`--row-h`, `--field-h`, `--gap`), not spacing primitives.

## Density-aware layout tokens

These shift with the **Density** toolbar (compact / cozy / comfortable):

- `--row-h` — list / table row height
- `--field-h` — form field height
- `--card-pad` — card inner padding
- `--gap` — default gap between siblings inside a card
