## Density override

`--radius`, `--radius-lg`, and `--radius-sm` shrink at `data-density="compact"` (6 / 10 / 4) and grow at `data-density="comfortable"` (10 / 14 / 6). Try the **Density** toolbar above.

## Backwards-compat aliases

`--radius-md` aliases the canonical `--radius` so shadcn primitives that read `--radius-md` keep resolving through density overrides. `--radius-xs` (4px) and `--radius-xl` (16px) are also kept for legacy use, but new work should use only `sm` / default / `lg` / `pill`.
