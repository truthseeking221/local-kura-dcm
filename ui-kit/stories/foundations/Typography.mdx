# Typography

**Noto Sans** (Latin + Khmer) for body and headings; **JetBrains Mono** for codes, MRNs, and any number that must align in a column.

The semantic classes below are defined in `tokens.css` (`@layer base`) and read directly from the type-scale tokens. Switch the **Density** toolbar between `Compact` and `Comfortable` — body, sm, xs, h, and lg rebind so type compresses without recompiling.

## Rules

- Body never below **11px**. Compact density baseline is **12.5px**.
- Tabular numerals (`font-variant-numeric: tabular-nums`) on tables, totals, and any column where digits must align.
- Khmer rendering: include both Latin and Khmer in samples — Noto Sans Khmer falls back automatically via `--font-family-sans`.
- The semibold-650 weight (`--weight-semibold650`) is reserved for tabular numeric emphasis (totals, counts) and the display/h1/h2 headings.
